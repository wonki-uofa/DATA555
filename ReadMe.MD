## Data 555 Project Repository
### 2026 Fall
#### Project 1 : Regression

This project predicts TSLA stock prices using linear regression.
I conducted correlation analysis using heatmaps and verified trends using regression scatter plots.
In addition to a multiple linear regression model, I applied a Ridge regression model to examine the impact of regularization on the prediction results.

#### Project 2 : Binary Classification

This project focuses on pumpkin seed classification.
Logistic regression was used as the baseline model, and I attempted to improve performance through feature selection and hyperparameter tuning.
Furthermore, I adopted a Random Forest model which is capable of learning non-linear patterns for building a higher-performing predictive model.
